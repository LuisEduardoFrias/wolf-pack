# Inglish

# wolf-pack

![Texto alternativo para la imagen](icon.png)

Wolf-pack is a package based on 'DaJTs' that simplifies data management locally. It works with encrypted JSON, uses HTTP nomenclature for ease of use, allows for relational and non-relational data storage, and acts as a lightweight, fast database ideal for small projects.

# Español

# wolf-pack

Wolf-pack es un paquete 📦 basada en 'DaJTs' que simplifica la gestión de datos de forma localmente, trabaja con Json encriptado, utiliza la nomenclatura http para mayor facilidad uso, permite almacenar datos de manera relacional y no relacional, actua como una base de datos ligera, rapida, ideal para proyectos pequeños.
